# مطعم عمو عزيز — قائمة الطعام الرقمية
# Amo Aziz Restaurant — Digital Menu

قائمة طعام ثلاثية اللغات (عربي · فرنسي · إنجليزي) مصمَّمة للهاتف أولاً.
موقع ثابت بلا خادم وبلا خطوة بناء — يفتح مباشرة ويُنشر مجاناً.

A trilingual (Arabic · French · English), mobile-first restaurant menu.
Static site, no server, no build step.

---

## التشغيل محلياً · Run locally

```bash
cd amo-aziz-menu
python3 -m http.server 8000
# افتح  http://localhost:8000
```

> افتحه عبر خادم محلي لا بنقر مزدوج على الملف — الصفحة تقرأ `data/menu.json`
> عبر `fetch`، وهذا يتطلب `http://` لا `file://`.

## تعديل الأطباق والأسعار · Editing the menu

**كل المحتوى في ملف واحد: `data/menu.json`. لا تحتاج لمس أي كود.**

```jsonc
{
  "id": "pizza",            // معرّف ثابت — لا تغيّره بعد النشر
  "category": "pizza",      // من قائمة categories
  "price": 250,             // رقم فقط، أو null إذا كان السعر بالطلب
  "image": "pizza",         // اسم الصورة بلا مقاس ولا امتداد
  "name": { "ar": "…", "fr": "…", "en": "…" },
  "desc": { "ar": "…", "fr": "…", "en": "…" }
}
```

| أريد أن… | افعل |
|---|---|
| أغيّر سعراً | عدّل `price` |
| أخفي طبقاً مؤقتاً | احذف كائنه من `dishes` |
| أضيف طبقاً | انسخ كائناً موجوداً وغيّر `id` و`image` |
| أغيّر ترتيب الأقسام | رتّب مصفوفة `categories` |
| أضيف ساعات العمل | املأ `openingHours` (حالياً `null` فلا يظهر القسم) |
| أغيّر رقم الواتساب | عدّل `whatsapp` (بلا مفتاح دولة) |
| أغيّر مفتاح الدولة | عدّل `countryCode` — في نفس الملف مع بقية أرقام التواصل |
| أنقل الموقع إلى نطاق آخر | عدّل `siteUrl` في `js/config.js` **فقط** ثم شغّل `node tools/build-seo.mjs` — يحدّث canonical و og:url و og:image و robots.txt و sitemap.xml معاً |

### إضافة صورة طبق جديد

ضع الصورة **مربّعة** في `assets/dishes/` بثلاثة مقاسات:

```
assets/dishes/<اسم>-400.webp
assets/dishes/<اسم>-800.webp
assets/dishes/<اسم>-1200.webp
```

ثم اكتب `"image": "<اسم>"` في الطبق. إن لم تتوفر صورة، اجعل `"image": null`
وستظهر البطاقة بحالة «لا تتوفر صورة» بشكل أنيق بدل أن تنكسر.

## ما الذي يعمل · Features

- **ثلاث لغات أصلية** — العربية RTL افتراضياً، الفرنسية والإنجليزية LTR.
  التخطيط يتغيّر فعلياً عبر الخصائص المنطقية (`inline`/`block`) لا بقلب الصفحة.
- **اللغة محفوظة** في المتصفح، وتبديلها **يحافظ على القسم المفتوح والطبق المعروض**
  (يوجد مبدّل لغة داخل نافذة الطبق لأن النافذة تحجب الترويسة).
- **شريط الشيف أعلى الصفحة** بصورة دائرية بمقاس ثابت (96px على الهاتف،
  132px على الشاشات الأكبر) — لا تتمدد ولا تُقصّ عشوائياً.
- بحث فوري في الأسماء والأوصاف **بثلاث لغات معاً**، مع تطبيع عربي:
  «منقوشه» تجد «منقوشة»، والتشكيل وصور الألف والهمزة لا تمنع النتيجة.
- فلترة حسب القسم.
- نافذة تفاصيل الطبق + اقتراحات من القسم نفسه.
- **سلة طلب**: يجمع الزبون عدة أطباق بكميات، يكتب ملاحظاته أو إضافاته،
  ثم يرسل الطلب كاملاً **في رسالة واتساب واحدة** فيها التفصيل والإجمالي.
  السلة محفوظة في المتصفح فلا تضيع إن أغلق الصفحة.
- **لا يمكن إرسال طلب فارغ**: ما دامت السلة فارغة لا يوجد رابط واتساب في
  الصفحة أصلاً — الزر يقول «اختر طبقاً أولاً» وينقل الزبون إلى الأطباق.
- بطاقات بعمودين على الهاتف على نسق القائمة المطبوعة، وزر «+» للإضافة السريعة.
- شريط سلة ثابت أسفل الشاشة يعرض العدد والإجمالي (في متناول الإبهام).
- حالة واضحة عند غياب الصورة، وحالة واضحة عند عدم وجود نتائج بحث.
- خطوط مستضافة محلياً — لا اعتماد على أي CDN خارجي.

## الأداء · Performance

- صور WebP بثلاثة مقاسات مع `srcset` — الهاتف يحمّل نسخة 400px (~35 KB) فقط.
- `loading="lazy"` لكل صور الأطباق + `LQIP` مضبّب يظهر فوراً قبل التحميل.
- لا إطار عمل، لا خطوة بناء، لا اعتماديات وقت التشغيل. JS ≈ 10 KB.
- الخطوط بـ `unicode-range` — الزائر الفرنسي لا يحمّل الخط العربي إطلاقاً.

## الوصولية · Accessibility

مساحات لمس ≥ 48px · تباين عالٍ · تسميات ARIA · تنقّل بلوحة المفاتيح ·
رابط «تخطَّ إلى القائمة» · احترام `prefers-reduced-motion` · `lang` و`dir` صحيحان.

## النشر · Deploy

أي استضافة ملفات ثابتة تعمل بلا إعداد: GitHub Pages، Netlify، Vercel.
ارفع محتوى المجلد كما هو. للـ QR Code: ولّد رمزاً يشير إلى رابط الموقع بعد النشر.

### بعد أي تعديل على القائمة

```bash
node tools/build-seo.mjs      # يحدّث Schema.org داخل index.html و sitemap.xml
```

ثم زِد `cacheVersion` في `js/config.js` و`VERSION` في `sw.js` بنفس القيمة،
حتى يحصل من زار الموقع سابقاً على الأسعار الجديدة فوراً بدل النسخة المحفوظة.

### أدوات المطوّر (اختيارية)

`tools/build-share-card.mjs` يعيد توليد صورة معاينة واتساب. يحتاج playwright:

```bash
npm install          # يثبّت playwright كاعتمادية تطوير فقط
npx playwright install chromium
node tools/build-share-card.mjs
```

الموقع نفسه **بلا أي اعتمادية وقت تشغيل** — هذه الأدوات لا تُرفَع إلى المتصفح.

## المشاركة على واتساب والسوشيال · Sharing

الرابط مهيّأ للمعاينة الاحترافية على واتساب وفيسبوك وتيليجرام وX:

- `og:image` صورة **1200×630 بصيغة JPEG** (`assets/brand/share-card-1200x630.jpg`)
  — JPEG قصداً لأن واتساب لا يعرض WebP بثبات في المعاينة.
- روابط مطلقة في `og:image` و`og:url` و`canonical` — الزاحفات لا تحلّ المسارات النسبية.
- `twitter:card = summary_large_image`.
- بيانات Schema.org من نوع `Restaurant` + `Menu` بكل الأصناف والأسعار.
- زر **«شارك القائمة»** يستخدم Web Share API على الهاتف (فيفتح واتساب وتيك توك
  وإنستغرام مباشرة)، ويسقط إلى نسخ الرابط على سطح المكتب.

**اختبار المعاينة قبل النشر للزبائن:**
[Facebook Debugger](https://developers.facebook.com/tools/debug/) ·
[X Card Validator](https://cards-dev.twitter.com/validator).
واتساب يخزّن المعاينة مؤقتاً — بعد أي تعديل على الصورة أو العناوين
مرّر الرابط في أداة فيسبوك أولاً واضغط *Scrape Again*.

## العمل بلا إنترنت · Offline

`sw.js` يخزّن هيكل الصفحة والخطوط عند أول زيارة، ويخزّن كل صورة عند أول
عرض لها. `data/menu.json` يُعرض من المحفوظ فوراً ويُحدَّث في الخلفية،
فالأسعار لا تتأخر. النتيجة: القائمة تفتح داخل المطعم حتى مع شبكة ضعيفة،
ويمكن إضافتها إلى الشاشة الرئيسية — دون أن يكون التثبيت مطلوباً.

## مصادر المحتوى — اقرأ `SOURCES.md`

الملف يوثّق مصدر كل قيمة في القائمة. الخلاصة:

**محسوم ومؤكَّد من صاحب المشروع:**

1. **«فول حلبي» بسعرين** (200 و150) — الملصق يسمّيهما بالاسم نفسه.
   مُيِّزا بـ «بالطحينة» و«سفري» من وصف كل طبق وصورته.
2. **وحدات التسعير** — الفلافل والصفيحة **للحبة**، والكبة **للطبق**، تظهر للزوار.

**اجتهادات لم تُراجَع بعد:**

3. **الترجمات الفرنسية والإنجليزية** اقتراحات مني — المصدر عربي فقط.
4. **الأوصاف** كتبتُها من الصور فقط — لا مكوّنات ولا معلومات حساسية (غير موجودة في المصدر).
5. **مفتاح الدولة 222** استنتاج لا نصّ صريح.
6. **ساعات العمل غير موجودة** في أي مصدر — القسم مخفي حتى تملأ `openingHours`.
