# مطعم عمو عزيز — قائمة الطعام الرقمية
# Amo Aziz Restaurant — Digital Menu

قائمة طعام ثلاثية اللغات (عربي · فرنسي · إنجليزي) مصمَّمة للهاتف أولاً.
موقع ثابت بلا خادم وبلا خطوة بناء — يفتح مباشرة ويُنشر مجاناً.

A trilingual (Arabic · French · English), mobile-first restaurant menu.
Static site, no server, no build step.

---

## التشغيل محلياً · Run locally

```bash
python3 -m http.server 8000
# افتح  http://localhost:8000
```

> افتحه عبر خادم محلي لا بنقر مزدوج على الملف — الصفحة تقرأ `data/menu.json`
> عبر `fetch`، وهذا يتطلب `http://` لا `file://`.

---

## تعديل الأطباق والأسعار · Editing the menu

**كل المحتوى في ملف واحد: `data/menu.json`. لا تحتاج لمس أي كود.**

```jsonc
{
  "id": "pizza",            // معرّف ثابت — لا تغيّره بعد النشر
  "category": "pizza",      // من قائمة categories
  "price": 250,             // رقم فقط، أو null إذا كان السعر بالطلب
  "image": "pizza",         // اسم الصورة بلا مقاس ولا امتداد
  "name": { "ar": "…", "fr": "…", "en": "…" },
  "desc": { "ar": "…", "fr": "…", "en": "…" }
}
```

| أريد أن… | افعل |
|---|---|
| أغيّر سعراً | عدّل `price` |
| أخفي طبقاً مؤقتاً | احذف كائنه من `dishes` |
| أضيف طبقاً | انسخ كائناً موجوداً وغيّر `id` و`image` |
| أغيّر ترتيب الأقسام | رتّب مصفوفة `categories` |
| أضيف ساعات العمل | املأ `openingHours` (حالياً `null` فلا يظهر القسم) |
| أغيّر رقم الواتساب | عدّل `whatsapp` (بلا مفتاح دولة؛ المفتاح `COUNTRY_CODE` في `js/app.js`) |

### إضافة صورة طبق جديد

ضع الصورة **مربّعة** في `assets/dishes/` بثلاثة مقاسات:

```
assets/dishes/<اسم>-400.webp
assets/dishes/<اسم>-800.webp
assets/dishes/<اسم>-1200.webp
```

ثم اكتب `"image": "<اسم>"` في الطبق. إن لم تتوفر صورة، اجعل `"image": null`
وستظهر البطاقة بحالة «لا تتوفر صورة» بشكل أنيق بدل أن تنكسر.

## ما الذي يعمل · Features

- **ثلاث لغات أصلية** — العربية RTL افتراضياً، الفرنسية والإنجليزية LTR.
  التخطيط يتغيّر فعلياً عبر الخصائص المنطقية (`inline`/`block`) لا بقلب الصفحة.
- **اللغة محفوظة** في المتصفح، وتبديلها **يحافظ على القسم المفتوح والطبق المعروض**
  (يوجد مبدّل لغة داخل نافذة الطبق لأن النافذة تحجب الترويسة).
- **شريط الشيف أعلى الصفحة** بصورة دائرية بمقاس ثابت (96px على الهاتف،
  132px على الشاشات الأكبر) — لا تتمدد ولا تُقصّ عشوائياً.
- بحث فوري في الأسماء والأوصاف **بثلاث لغات معاً**.
- فلترة حسب القسم.
- نافذة تفاصيل الطبق + اقتراحات من القسم نفسه.
- **سلة طلب**: يجمع الزبون عدة أطباق بكميات، يكتب ملاحظاته أو إضافاته،
  ثم يرسل الطلب كاملاً **في رسالة واتساب واحدة** فيها التفصيل والإجمالي.
  السلة محفوظة في المتصفح فلا تضيع إن أغلق الصفحة.
- **لا يمكن إرسال طلب فارغ**: ما دامت السلة فارغة لا يوجد رابط واتساب في
  الصفحة أصلاً — الزر يقول «اختر طبقاً أولاً» وينقل الزبون إلى الأطباق.
- بطاقات بعمودين على الهاتف على نسق القائمة المطبوعة، وزر «+» للإضافة السريعة.
- شريط سلة ثابت أسفل الشاشة يعرض العدد والإجمالي (في متناول الإبهام).
- حالة واضحة عند غياب الصورة، وحالة واضحة عند عدم وجود نتائج بحث.
- خطوط مستضافة محلياً — لا اعتماد على أي CDN خارجي.

## الأداء · Performance

- صور WebP بثلاثة مقاسات مع `srcset` — الهاتف يحمّل نسخة 400px (~35 KB) فقط.
- `loading="lazy"` لكل صور الأطباق + `LQIP` مضبّب يظهر فوراً قبل التحميل.
- لا إطار عمل، لا خطوة بناء، لا اعتماديات وقت التشغيل. JS ≈ 10 KB.
- الخطوط بـ `unicode-range` — الزائر الفرنسي لا يحمّل الخط العربي إطلاقاً.

## الوصولية · Accessibility

مساحات لمس ≥ 48px · تباين عالٍ · تسميات ARIA · تنقّل بلوحة المفاتيح ·
رابط «تخطَّ إلى القائمة» · احترام `prefers-reduced-motion` · `lang` و`dir` صحيحان.

## النشر · Deploy

**الموقع منشور تلقائياً على GitHub Pages.** كل دفعة إلى `main` تُعيد النشر خلال
دقيقة تقريباً عبر `.github/workflows/deploy-pages.yml` — لا خطوات يدوية.

يعمل أيضاً بلا تعديل على Netlify أو Vercel (اسحب المجلد وأفلته).
للـ QR Code: ولّد رمزاً يشير إلى رابط الموقع بعد النشر واطبعه على الطاولات والواجهة.

## ⚠️ قبل النشر للزبائن — اقرأ `SOURCES.md`

الملف يوثّق مصدر كل قيمة، ويحدد ما يحتاج تأكيدك. أهمها:

1. **«فول حلبي» بسعرين** (200 و150) — تعارض موجود في المصدر نفسه، لم أختر أحدهما.
2. **الترجمات الفرنسية والإنجليزية** اقتراحات مني — المصدر عربي فقط.
3. **الأوصاف** كتبتُها من الصور فقط — لا مكوّنات ولا معلومات حساسية (غير موجودة في المصدر).
4. **مفتاح الدولة 222** استنتاج لا نصّ صريح.
5. **ساعات العمل غير موجودة** في أي مصدر — القسم مخفي حتى تملأه.
