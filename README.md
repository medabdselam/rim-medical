# Rim Medical — متجر المعدات الطبية 🏥

موقع متكامل لمتجر معدات طبية، يتكون من:

| الجزء | المسار | الوصف |
|---|---|---|
| موقع الزبائن | `index.html` | موقع عرض فاخر ثلاثي اللغات (عربي / فرنسي / إنجليزي) |
| لوحة التحكم | `admin.html` | إدارة المنتجات والأرقام والشعار — محمية بكلمة مرور |
| البيانات الاحتياطية | `data.js` | نسخة تظهر إذا تعذّر الاتصال بقاعدة البيانات |
| طبقة البيانات | `store.js` | الوسيط الوحيد بين الصفحات وقاعدة بيانات Supabase |

### صفحات أخرى منشورة من نفس المستودع

| الصفحة | المسار | الوصف |
|---|---|---|
| سند | `sened.html` · `sened-admin.html` | موقع سند ثلاثي اللغات مع لوحة تحكم خاصة |
| صفحة المطوّر | `developer.html` | معرض أعمال ونبذة، مرتبطة من تذييل الموقع |
| قائمة عمو عزيز | `amo-aziz-menu/` | ⚠️ نُقلت إلى مستودع مستقل — انظر `amo-aziz-menu/README.md` |

**الدخول إلى لوحة التحكم:** بكلمة المرور التي حددتَها، عبر حساب حقيقي في
Supabase Auth (البريد `senedmedical@gmail.com`). يمكنك تغيير كلمة المرور في أي
وقت من تبويب "أرقام التواصل" داخل اللوحة.

**ما يمكنك إدارته من اللوحة:** المنتجات (بعدة صور لكل منتج)، الفئات (إضافة/تعديل/حذف)،
رقما واتساب، الإحصائيات، روابط السوشيال، والشعار.

## 1) المعاينة محلياً على جهازك

أبسط طريقة: انقر نقراً مزدوجاً على `index.html` وسيفتح في المتصفح.

الطريقة الأفضل (تضمن عمل كل شيء 100% وربط اللوحة بالموقع):

```bash
# إذا كان لديك Python (موجود غالباً في كل الأجهزة):
python3 -m http.server 8000
# ثم افتح في المتصفح:
# الموقع:        http://localhost:8000
# لوحة التحكم:   http://localhost:8000/admin.html
```

---

## 2) كيف يرتبط الموقع بلوحة التحكم؟ (اقرأ هذا جيداً)

النظام يعمل على **قاعدة بيانات Supabase**، فالتعديلات تصل لكل الزوار فوراً:

1. تسجّل الدخول إلى `admin.html` بكلمة مرورك.
2. تعدّل ما تريد (منتجات، أرقام، شعار، تقييمات).
3. تضغط **"نشر"** → تُكتب البيانات في القاعدة → **يراها كل الزوار فوراً**،
   بلا رفع ملفات ولا لمس كود.

**لا تحتاج خطوة "تنزيل data.js ورفعه" إطلاقاً** — تلك كانت طريقة النسخة الأولى.

ماذا يبقى لـ `data.js`؟ نسخة احتياطية فقط: إذا تعذّر الوصول إلى القاعدة (انقطاع
إنترنت مثلاً) يعرض الموقع آخر نسخة محفوظة في متصفح الزائر، وإن لم توجد فمحتوى
`data.js`. يمكنك تنزيل نسخة احتياطية محدَّثة في أي وقت من تبويب "النشر".

> **ملاحظة أمنية:** مفتاح Supabase الموجود في `store.js` مفتاح عام مخصص للنشر
> في كود المواقع، وليس سراً. الحماية الحقيقية في قواعد **Row Level Security**
> داخل القاعدة: القراءة للجميع، والكتابة لحسابك أنت فقط.

## 3) النشر المجاني خطوة بخطوة (GitHub Pages)

الموقعان (الزبائن + اللوحة) يُنشران معاً لأنهما في نفس المجلد.

1. أنشئ حساباً في [github.com](https://github.com) إن لم يكن لديك.
2. أنشئ مستودعاً جديداً (Repository) باسم مثل `rim-medical` واجعله **Public**.
3. ارفع كل ملفات هذا المجلد إليه (زر **Add file → Upload files** يسمح بالسحب والإفلات).
4. من صفحة المستودع: **Settings → Pages → Branch: main → Save**.
5. بعد دقيقة أو دقيقتين سيكون موقعك متاحاً على:
   - الموقع: `https://اسم-حسابك.github.io/rim-medical/`
   - لوحة التحكم: `https://اسم-حسابك.github.io/rim-medical/admin.html`

### تحديث المحتوى لاحقاً (بدون لمس الكود ولا GitHub)
1. افتح لوحة التحكم وسجّل الدخول.
2. عدّل ما تريد (منتجات، أرقام، شعار).
3. اضغط **نشر**. هذا كل شيء — التغيير يظهر لكل الزوار في نفس اللحظة.

> لا تحتاج رفع أي ملف إلى GitHub إلا إذا غيّرت الكود نفسه.

بدائل مجانية أخرى تعمل بنفس الطريقة: [Netlify](https://netlify.com) (سحب وإفلات
المجلد كاملاً) أو [Vercel](https://vercel.com).

## 4) بنية قاعدة البيانات (Supabase)

القاعدة قائمة وتعمل. هذا توثيقها للرجوع إليه عند الصيانة:

| الجدول | المحتوى |
|---|---|
| `site_data` | صف واحد (`id = 1`) فيه عمود `data` من نوع `jsonb` يحمل كل المنتجات والإعدادات |
| `reviews` | تقييمات الزبائن: `name`, `reviewer_type`, `rating`, `comment`, `approved`, `created_at` |

**قواعد الحماية (Row Level Security):**
- `site_data`: القراءة للجميع · الكتابة لحساب المالك المسجَّل فقط.
- `reviews`: القراءة للتقييمات المعتمدة (`approved = true`) للجميع · الإضافة
  متاحة لأي زائر · التعديل والحذف والاطلاع على غير المعتمد لحساب المالك فقط.

**الملف الوحيد الذي يلمس القاعدة هو `store.js`.** كل الصفحات تتعامل معه عبر
`RimStore` فقط ولا تعرف شيئاً عن Supabase — أي تغيير في مزوّد البيانات مستقبلاً
يتم داخل هذا الملف وحده.

### ما لم يُنفَّذ بعد
الصور ما تزال تُخزَّن كنص Base64 داخل `site_data` بدل **Supabase Storage**.
هذا يكبّر حجم الصف ويبطئ التحميل مع كثرة المنتجات. الترقية عند الحاجة:
أنشئ Bucket عاماً باسم `images`، وارفع الصور إليه، واحفظ الروابط بدل النص.

## 5) ملاحظات مهمة

- **الأمان:** الدخول إلى اللوحة عبر Supabase Auth بحساب حقيقي، والكتابة محمية
  بقواعد RLS في القاعدة نفسها — لا يكفي تجاوز واجهة المتصفح للكتابة.
  لوحة التحكم لا تُفهرس في محركات البحث (`noindex`).
- **أرقام واتساب:** تُكتب بالصيغة الدولية بدون `+` (مثال: `22228646987`).
  رقم الزبائن ورقم المؤسسات منفصلان تماماً ويُعدَّلان من تبويب "أرقام التواصل".
- **الصور:** تُضغَط تلقائياً عند الرفع من اللوحة. تُخزَّن حالياً داخل بيانات
  الموقع كنص Base64 — أبقِ عددها وأحجامها معقولة حتى تتم ترقية التخزين
  (القسم 4 أعلاه).
- **تعديلات غير منشورة:** ما تعدّله في اللوحة قبل الضغط على "نشر" يبقى في
  متصفحك، وقد تراه أنت على الموقع دون بقية الزوار. اضغط "نشر" ليراه الجميع.
- **إضافة لغة رابعة:** كل النصوص في كائن `I18N` أعلى سكربت `index.html` —
  انسخ قسم `en` وترجمه.
- **آراء الزبائن:** نصوص تجريبية (Placeholder) داخل كائن `I18N` قسم `reviews`،
  عدّلها بآراء حقيقية عندما تتوفر.
